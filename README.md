# 🚀 University Placement Management System

A robust system designed to streamline the recruitment process between students and companies.

## 🔥 Key Features
* **Dual Roles:** Dedicated dashboards for Students and Recruitment Officers.
* **Smart Search:** Implemented advanced search algorithms for student filtering.
* **Database Design:** Optimized schema using SQLAlchemy and PostgreSQL.
* **Modern Backend:** Built with Python & Flask for high scalability.

## 🛠️ Tech Stack
* **Language:** Python
* **Web Framework:** Flask
* **Database:** PostgreSQL & SQLAlchemy
* **Frontend:** HTML, CSS (Clean & Premium UI)
